Unidye v1.2.0 | Released December 30, 2024
-----------------------------------------
• Added EMI compat
• Added REI compat
• Added JEI compat
• Slightly tweaked the recipe logic
Dev commentary
This update is not a big one, but it is really important.
Now you can view unidye recipes using EMI and REI, and you can read text
guides in-game using JEI (because JEI does not really support special recipes like
leather armor dyeing, so I could not make it display unidye's recipes, and I wrote
in-game documentation instead!). Personally, I would prefer EMI and REI to view the recipes.

The update also includes some recipe tweaks but
it is not that noticible, just some qol changes.

Moving forward, I can finally start working on porting the mod
to the newer versions, so stay tuned!
